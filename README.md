# Federico Marcenac | Portfolio

Portfolio personal de **Federico Marcenac**, estudiante de la Tecnicatura Universitaria en Programación en UTN Bahía Blanca, interesado en el desarrollo de software, desarrollo web y tecnología IT.

El proyecto busca presentar mi perfil profesional, conocimientos técnicos, formación académica y proyectos desarrollados.

## 🌐 Sitio web

**Portfolio online:** [Ver portfolio](https://federicomarcenac.github.io/PortafolioFedericoMarcenac/)

## ✨ Características

- Diseño moderno con identidad visual tecnológica.
- Interfaz oscura con tonalidades azules e iluminación.
- Diseño responsive para computadoras, tablets y celulares.
- Secciones de presentación y perfil profesional.
- Tecnologías y conocimientos organizados por categorías.
- Galería de proyectos con enlaces a repositorios.
- Formación académica y experiencia práctica.
- Sección de contacto y redes profesionales.
- Animaciones y efectos visuales.

## 💻 Ejecutar localmente

Clonar el repositorio:

```bash
git clone https://github.com/FedericoMarcenac/PortafolioFedericoMarcenac.git
```

Ingresar a la carpeta:

```bash
cd PortafolioFedericoMarcenac
```

Instalar dependencias:

```bash
npm install
```

Iniciar el servidor de desarrollo:

```bash
npm run dev
```

Generar la versión de producción:

```bash
npm run build
```

## 🚀 Despliegue

El proyecto utiliza GitHub Pages y GitHub Actions para automatizar la publicación.

Cada actualización enviada a la rama `main` ejecuta el proceso de compilación y despliegue.
